# Emotion Detector

## Project Description

Emotion Detector is a web-based application that detects emotions from user-provided text using the IBM Watson Natural Language Processing service.

The application analyzes the input text and identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion expressed in the input.

## Technologies Used
